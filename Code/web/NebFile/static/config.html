Nebulae settings

Files
Wi-Fi
The built-in Wi-Fi: the access point this page runs on (or the home network if the stick has one). Its radio is heard in the audio as a ticking buzz. Off also closes this page.
Power regulator
Keeps the CPU from sleeping: each wake-up is heard as a tone or a click. off = normal. yield and shell = a spinner keeps the cores awake (shell is stronger, but slows Csound on a Pi 3). nohlt = a kernel option, the quietest. Choosing nohlt, or leaving it, restarts the Pi.
No PWM
The file (next) and freeze LEDs are only fully on or off, without PWM dimming. Their PWM can be heard in the audio.
LED stagger
The LED PWM channels switch on at different moments of the PWM cycle, so there is no big current step all at once (heard as a tone). The brightness looks the same.
Services no sounds
On: the Pi board's own LEDs off, USB off while the stick is not in use, the system log kept in RAM, and network time sync, netctl-auto and scheduled jobs stopped.
LED dim
How bright every LED on the front panel is, 0 = off, 100 % = full.

nebio input rates

Encoders (scan)
Hz
How often nebio reads the encoders, 100–2000 Hz. Every other input is read on every nth of these scans. Default 1200 Hz.
Buttons (digital)
How often the buttons, encoder clicks and gate inputs are read. They are read inside the encoder scan, on every nth scan, so only these rates are possible. Default 400 Hz.
Knobs and CV (ADC)
How often the knobs and CV inputs are read (the MCP3208), and the fastest a new value reaches the instrument. Read inside the encoder scan, on every nth scan, so only these rates are possible. Default 400 Hz.

Nebulae

Restart Nebulae
For when an instrument has jammed. Saves the instrument (knob values and encoder pages), then restarts Nebulae, which loads the same instrument again. The sound stops for a while. If Nebulae does not answer, it is restarted without saving.
